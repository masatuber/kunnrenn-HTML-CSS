●背景に画像を貼り付ける

▼画像の指定

　background-image　プロパティ

　背景色同様にbackground-～のプロパティは、backgroundプロパティで一括指定可
　※backgroundプロパティは、7/21(火)参照

　値
　　url("パス")

▼画像は2種以上を同時指定可
「,(コンマ)」区切り

　url("～"),url("～")
　　　下　　　上

　とすると、重ね順は、先に書いたものが下になる。
　backgroundプロパティで一括指定する時、他のプロパティと値の間は、半角スペースで区切る。

▼色と画像の同時指定可

　red url("～")
　下　　上

　とすると、重ね順は、先に書いたものが下になる。

▼背景画像の繰返しを指定

　background-repeat　プロパティ

　値
　　no-repeat	繰返しなし
　　repeat	全面に繰返し
　　repeat-x	x軸(横)方向のみ繰返し
　　repeat-y	y軸(縦)方向のみ繰返し

【注意】
　background-repeatがrepeat以外の時は、「どこに」が必要になる。

　background-position　プロパティ
　
　値         　　  --┐
　　left-----┐　　  │
　　right    │横軸  │この値は、
    center---┘  　　│　topなら、エリア上部と写真上部
    top------┐ 　　 │　centerなら、エリア中央と写真中央
    bottom 　│縦軸  │のように、両方の上下左右中央を意味している。
    center---┘  　　│
              　　 --┘
　数値との組み合わせも可←%での指定は使用しない。基本的には、pxを使用。
　半角スペース区切り
　top 10px left 20px
　上から10px、左から20pxの位置
　※横軸、縦軸書き順はなし。
　
▼背景に貼る画像を拡大縮小して、1枚でエリアを最大限カバーする

　background-size　プロパティ

　値
　　contain　　画像がエリアからはみ出さない最大のサイズに

　　cover	画像がエリアからはみ出してしまうが、エリア全面に画像が出るように

　参考URL：https://haniwaman.com/background/ 
 　　　　　https://jajaaan.co.jp/css/background-size/

　【注意】
　positionの後に「/(スラッシュ)」区切りで指定する。
　例）top /contain
      right bottom /cover

  拡大すると画像の粗も見えてくる場合もあるため、それなりの画像を用意する

●表を作成する

▼表全体を指定する

　<table>～</table>
　
　このタグは、子要素にテーブルの部品を示す
 ※テーブルの～という意図で、頭にｔ(ティー)がつく
						--┐
　<thead>～</thead>	表の見出し行を指定	　│
　<tbody>～</body>	表のデータ部の行を指定　 │複数行をまとめて指定
　<tfoot>～</tfoot>	表の集計部の行を指定     │
						--┘
　<tr>～</tr>		1行を指定
　<caption>～</caption>	表のキャプションを指定
　以外を持つことができない。

　【注意】
　Googleの推奨ルールを守った方が、評価は上がる。
　また、何も記載しなければ、ブラウザ側としてはtbodyの認識をしてくれるが、
　昔にtbody記入必須だった時があり、ルール変更があった場合、修正が必要になるため

▼<thead>～</thead>
　<tbody>～</body>
　<tfoot>～</tfoot>
　は、子要素にできるのは<tr>～</tr>のみ

　<tr>～</tr>で1行を示しており、その行がthead,tbody,tfootのどれに該当するかを
　示すことが推奨されている。

▼<tr>～</tr>の子要素は
　<th>～</th>	見出しセル
　<td>～</td>	データセル
　の2つのみとなっている。
　基本、<tr>の子要素が全て<th>の行は、<thead>に指定していく

　縦連携	rowspan属性

　1000個以上の連結は保障されていない。

●表のCSSについて

▼表は枠線をつける事が多い
　枠線をつけるために使用するタグは、
　　<table>
　　<th>
　　<td>
　となっており、すべてに枠線を指定すると
　┌─────┐
　│□　□　□│
　│　　　　　│
　│□　□　□│（個々に囲われているため二重線に見える)
　└─────┘
　のように表示される。これを、
　┌─┬─┬─┐
　│　│　│　│
　├─┼─┼─┤
　│　│　│　│
　└─┴─┴─┘
　としたい時は、tableに

　　border-collapse:collapse;
　
　と指定する。

▼captionの表示位置について
　初期値では表の上部に表示される
　これを表の下部に表示したい時は、

　　caption-side: bottom;
  と指定する。

【注意】
border-collapseを設定する場合は、必ずtable,th,tdは線種、線色、太さを同じにしないと
ブラウザによって表示が乱れるため、まとめて設定が必要

CSS記入例)
table,th,td{
  border: 1px solid black;
}
