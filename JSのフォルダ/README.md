## 変数の定義について

①JavaScriptでは変数を使用する時に「この変数名を使用する」と宣言する必要がある。
宣言の方法は以前からある「var」に加えより有効範囲の狭い「let」が追加された（IEではletは使用不可）
開発時にはより有効範囲が狭い方が多人数開発をしやすいため現在はIEに対応しない場合letを使用するのが一般的となっている。

②JavaScriptでは
```text
・変数名の定義のみ
・変数名を定義し変数に値を格納する
```
のどちらも可能となっている

変数名の定義のみを行った場合その変数にはundefined と言う値が自動的に設定される。

・ 変数の定義は同時に複数可能
複数の変数を「、」区切りで書くことで1つのletで定義出来る。

変数名 a b c

を定義

let a,b,c;

・変数に値を格納

  代入演算子「=」を使用

JavaScriptでの「=」は=の右辺の値を左辺の変数（もしくは定数）に値を代入（格納）する
という演算子になっている
変数aに1を代入 a = 1
